## Проведені перевірки

Автоматичний прогін виконано на Windows із Node.js 22.19.0. Команди `npm test`, `npm run test:coverage`, `npm run typecheck`, `npm run lint` і збірка renderer через Vite завершилися успішно. SQLite видав попередження про експериментальний модуль. Ручний прогін у Electron і перевірка інсталятора залишаються відкритими.

### Покриття коду

Для повторного вимірювання виконай `npm run test:coverage`.

| Модуль                    |  Рядки |  Гілки | Функції |
| ------------------------- | -----: | -----: | ------: |
| `src/database.ts`         | 94,05% | 88,10% |    100% |
| `src/readingSummary.ts`   |   100% |   100% |    100% |
| Разом у межах вимірювання | 94,32% | 88,76% |    100% |

Node.js вимірює виконання JavaScript, який тестовий завантажувач отримує з TypeScript. Модулі Electron, React-компоненти та сценарії у вікні застосунку цими відсотками не охоплені. Наступні кандидати для розширення тестів — помилки відкриття бази, варіанти форматів обкладинок та обробка помилок у вікні застосунку.

## Аналіз відповідності вимогам

У репозиторії немає затвердженого переліку вихідних вимог курсової. Ця матриця спирається на README, погоджений сценарій користування та поточний код. Після отримання завдання викладача потрібно звірити формулювання й доповнити матрицю.

| Вимога                                                                    | Стан              | Підтвердження або відкрите питання                                                                                   |
| ------------------------------------------------------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------- |
| Локальний застосунок зі збереженням у SQLite                              | Реалізовано       | DB-01. У README зафіксовано перехід із `better-sqlite3` на `node:sqlite`. Цю зміну слід звірити з вимогами курсової. |
| Профіль, аватар, денна ціль і тема                                        | Реалізовано       | DB-02, DB-03. Ручний сценарій UI-01 очікує прогону.                                                                  |
| Бібліотека, пошук, обкладинки                                             | Реалізовано       | DB-04 перевіряє збереження. UI-02 перевіряє пошук та оновлення картки.                                               |
| Таймер із паузою, початковою та кінцевою сторінками                       | Реалізовано       | DB-05, DB-06. UI-03 очікує прогону.                                                                                  |
| Календар фактичного читання з обкладинками та деталями дня                | Реалізовано       | DB-07 перевіряє дані, UI-03 та UI-04 — відображення. Планування прибрано за погодженою зміною.                       |
| Денний і 7-денний підсумки                                                | Реалізовано       | ST-01 перевіряє підрахунок. UI-03 перевіряє його відображення.                                                       |
| Редагування й видалення книг, нотатки, мінітаймер, нагадування та експорт | Ще не реалізовано | Уточнити обов’язковість за затвердженим завданням.                                                                   |

Формальний відсоток готовності можна визначити після звірки з повним переліком вимог.
